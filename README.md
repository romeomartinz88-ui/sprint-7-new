# sprint-7-new
# Análisis de anuncios de venta de vehículos

Aplicación web construida con Streamlit y Plotly Express para explorar
un conjunto de datos de anuncios de venta de coches (`vehicles_us.csv`).

## Funcionalidad
- Botón para construir un histograma del kilometraje (odometer).
- Botón para construir un gráfico de dispersión de kilometraje vs. precio.

## Cómo ejecutarla localmente
pip install -r requirements.txt
streamlit run app.py
